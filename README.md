# 《反射之光：帮小明照亮目标》

面向初中生的“光的反射”交互式二维数字化教学资源。项目采用 HTML5、CSS3、原生 JavaScript 与 SVG 开发，无后端、无数据库、无在线接口、无外部素材依赖。

## 文件结构

```text
反射之光-课程项目/
├─ index.html              # 单页应用结构与 SVG 教学画面
├─ style.css               # 原有统一视觉与响应式布局
├─ animation.css           # 四个教学场景的120秒分镜动画
├─ challenge.css           # 五关光路挑战与移动端样式
├─ script.js               # 原有页面、动画、实验、基础任务与测验
├─ challenge-physics.js    # 射线、有限镜面、障碍、目标和连续反射计算
├─ challenge.js            # 五关交互、提示、演示、评价、解锁和存档
├─ README.md               # 运行与使用说明
└─ assets/
   ├─ README.txt
   └─ audio/
      └─ narration-script.txt
```

## 最简单运行方法

可以直接双击 `index.html` 运行。推荐在项目目录打开终端，运行：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。项目不需要 `npm install`，也不需要 API Key。

## 完整教学流程

首页 → 情境导入 → 约2分钟动画讲解 → 互动实验 → 光路挑战 → 知识检测 → 学习总结。

原有的两项基础任务保留在“光路挑战”页底部的“基础任务回顾”中。

## 主要功能

- 四场景、120秒二维教学动画，支持播放、暂停、继续、重播、前后切换、字幕与声音开关。
- 本地 MP3 接口缺少文件时自动回退到浏览器本地中文语音；语音不可用时字幕仍正常显示。
- 原互动实验支持拖动镜面控制点或使用滑杆，实时显示入射线、反射线、法线、入射角和反射角。
- 五关“光路挑战”：基础反射、绕过障碍、精准命中、二次反射、终极挑战。
- 第2关和第5关使用真实障碍碰撞，光线在最近障碍处停止，不会穿墙后命中目标。
- 第4关和第5关支持两面镜子独立调整，并进行“光源→镜子1→镜子2→目标”的真实连续反射计算。
- 所有镜面均按有限线段处理；只有射线传播正方向上的最近交点有效。
- 每关提供三级学习支架：思路提示、随当前角度变化的方向提示、半透明虚线参考光路。
- “演示正确解法”会平滑转动镜子并实时更新真实光路；双镜面关卡按镜子1、镜子2的顺序演示。
- 有效操作按一次完整的拖动或滑杆操作计数，不按每次移动事件重复计数。
- 每关根据操作次数和提示使用情况获得1—3星；使用高级提示不影响通关和后续关卡解锁。
- 关卡通过状态、最佳星级、解锁进度和总星数使用 `localStorage` 保存在当前浏览器。
- “重置闯关进度”需要连续两次确认；“重新开始本关”和“自己再试一次”不会删除其他关卡成绩。
- 五关完成后显示通关总结与总星数，可重新挑战或进入原有3道知识检测。

## 光路挑战操作

1. 在关卡选择页从已解锁关卡开始挑战。
2. 电脑端可拖动镜面端点或使用角度滑杆；触屏设备可直接用手指拖动镜面控制点。
3. 双镜面关卡先选择并调整镜子1，使第一次反射到达镜子2，再调整镜子2。
4. 遇到困难时依次点击“提示”“再给一点提示”“查看正确光路”。
5. 查看参考光路后可播放正确解法演示，也可以点击“自己再试一次”恢复本关初始状态。

## 手机端说明

约375px宽度下，关卡卡片改为单列，控制面板位于画布下方。为保持足够大的触摸区域，SVG画布允许局部横向滚动；镜面控制点、滑杆和主要按钮均支持 Pointer Events，可使用鼠标、触控笔或手指操作。

## 离线与声音说明

项目不请求外部图片、字体、接口或在线音频。正式 MP3 尚未生成，已预留：

```text
assets/audio/scene1.mp3
assets/audio/scene2.mp3
assets/audio/scene3.mp3
assets/audio/scene4.mp3
```

使用本地服务器时，同名文件存在则优先播放；缺少时不会影响页面其他功能。完整配音稿见 `assets/audio/narration-script.txt`。

核心动画讲解约2分钟；加入五关操作后，完整学习时间会随学生的尝试次数和提示使用情况变化。

## 教学内容说明

项目聚焦初中阶段基础内容：光的反射现象、入射光线、反射光线、法线、入射角、反射角，以及“反射角等于入射角”。五关挑战将这些概念用于单次反射、绕障、精确控制和连续两次反射问题。角度均以法线为基准。
